# campus-agent · v0.1

给本班同学用的校园助手。问它图书馆几点关门、奖学金怎么申、空调坏了找谁。

**这一版是 v0.1**：命令行里能一问一答。丑，但能跑。

> 这个文件夹是一份**完整可跑**的快照，单独拿走也能跑。
> 整个仓库有十二个版本，见[仓库根目录](../README.md)；每版改了什么，见 [CHANGELOG](../CHANGELOG.md)。

---

## 怎么跑

不需要装任何依赖（除非你想让 token 数精确，见下）：

```bash
cd campus-agent
python -m agent "一卡通丢了去哪补办"
```

想看它到底发了什么给模型：

```bash
python -m agent "转专业什么时候能申请" --debug
```

跑一遍自检（课程里每节的验收就是它）：

```bash
python tools/check.py
python -m unittest discover -s tests -v
```

## 三种模型后端

`agent/llm.py` 按顺序找，找到哪个用哪个：

| 后端 | 怎么开 | 说明 |
|---|---|---|
| 平台网关 | `export AGENT_GATEWAY=http://127.0.0.1:8787/api/llm/generate` | 课程内推荐，不用自己买 key |
| 任意 OpenAI 兼容 | `export OPENAI_API_KEY=sk-...` + `export OPENAI_BASE_URL=...` | 也支持 `AGENT_MODEL` 换模型 |
| 离线占位 | 什么都不配 | **不是模型回答**，只把最像的资料原文贴出来，别拿它当效果 |

`AGENT_GATEWAY` 用的就是课程平台那个接口。它在服务端拿 key，你的电脑上不留密钥。

让 token 数是真数（而不是估算）：

```bash
pip install tiktoken
```

不装也能跑，但日志里的 token 会有 10–20% 偏差。

## 已知问题（都是故意的，后面会一节一节修）

1. **资料是全塞进去的。** `main.py` 的 `build_messages()` 把当天所有资料拼成一坨。
   第 1 天只有 6 条所以没事；第 3 天涨到 37 条，窗口装不下，它就开始编。
2. **输出是纯文本。** 程序没法可靠地从里面取字段。想加个「自动填到报修单」就得靠正则猜。
3. **没有评测。** 改完提示词，你不知道是变好了还是只是碰巧。
4. **没有成本。** 日志里有 token，但没人换算成钱。
