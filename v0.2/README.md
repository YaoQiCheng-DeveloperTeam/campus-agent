# campus-agent · v0.2

给本班同学用的校园助手。问它图书馆几点关门、奖学金怎么申、明天下午哪间教室空着。

**这一版是 v0.2**：装得进窗口了，能查空教室，每次问花多少钱也知道了。

> 这个文件夹是一份**完整可跑**的快照，单独拿走也能跑。
> 仓库里一共十二个版本，一版一个文件夹；每一版改了什么，写在仓库根目录的 `CHANGELOG.md` 里。

---

## 怎么跑

不需要装任何依赖（除非你想让 token 数精确，见下）：

```bash
cd campus-agent
python -m agent "一卡通丢了去哪补办"
python -m agent "明天下午三教有空教室吗"      # 这一版新加的：真去查
```

想看它**为什么选了这个模型、往窗口里装了什么**：

```bash
python -m agent "转专业什么时候能申请" --debug
```

跑一遍自检（课程里每节的验收就是它）：

```bash
python tools/check.py                    # 10 条
python -m unittest discover -s tests -v  # 20 条
```

## 这一版改了什么

| 第一版的问题 | 这一版的做法 | 落在哪个文件 |
|---|---|---|
| 37 条资料 + 24 轮历史一起塞，窗口装不下，它开始编 | 按「和问题有多像」挑 3 条装进去，历史从最近往回装，问题永远最后一条 | `agent/context.py` |
| 模型吐出来的工具参数直接就用了，`"5"` 当整数、`top_k: 500` 也照查 | 先过 `schemas.check()`，类型 / 范围 / 多余字段一律挡回去，并把原因回传给模型让它重填 | `agent/schemas.py`、`agent/tools.py` |
| 什么题都走同一个模型，一拉账单八成花在不必要的地方 | 先判断难度和约束，挑「够用里最便宜」的那个；都不满足就降档并标 `degraded` | `agent/router.py` |

日志里多两列，`logs/run.jsonl`：

```json
{"model": "mini", "cost": 0.0032, "docs": 3, "in_tokens": 2579, "out_tokens": 207, "tool": null}
```

`cost` 是这一次的估算花费（元）。一整天问下来加一遍，就是你室友用它的真实成本。

## 三种模型后端

`agent/llm.py` 按顺序找，找到哪个用哪个：

| 后端 | 怎么开 | 说明 |
|---|---|---|
| 平台网关 | `export AGENT_GATEWAY=http://127.0.0.1:8787/api/llm/generate` | 课程内推荐，不用自己买 key |
| 任意 OpenAI 兼容 | `export OPENAI_API_KEY=sk-...` + `export OPENAI_BASE_URL=...` | 也支持 `AGENT_MODEL` 换模型 |
| 离线占位 | 什么都不配 | **不是模型回答**，只把最像的资料原文贴出来，别拿它当效果 |

`router.py` 里的 `mini / standard / reason` 是抽象档位；真接哪家，把 `MODELS` 换成那家的真实型号和单价即可。
价格表是量级参考，不是报价单。

`AGENT_GATEWAY` 用的就是课程平台那个接口。它在服务端拿 key，你的电脑上不留密钥。

让 token 数是真数（而不是估算）：

```bash
pip install tiktoken
```

不装也能跑，但日志里的 token 会有 10–20% 偏差。

│   ├── tools.py         工具本体；模型填表，代码验表再执行

├── tests/               20 条单测

## 已知问题（都是故意的，后面会一节一节修）

1. **找资料还是靠两个字重合。** 问「转专业要准备什么材料」，它先命中奖学金那条——
   因为「申请」「材料」在奖学金里出现得更多。这不是 bug，是这种土办法的上限，第 5 幕换检索。
2. **长了记不住。** 24 轮历史现在是"能装多少装多少"，聊到第 20 轮，最早的规则和约定就掉出去了。
3. **不会真的循环。** `tools.py` 里那份「解析问题猜参数」的东西是模型的替身；
   真循环（模型自己决定调几次、什么时候停）在第 4 幕。
4. **没有评测。** 改完提示词，你还是不知道是真变好还是碰巧——第 8 幕。
5. **单点。** 换模型要改代码里的表，没有自动降级重试；第 9 幕上线时补。
